# Торос · Конкурс прогнозов

Каркас проекта для [crewalv/toros_voting](https://github.com/crewalv/toros_voting).

- `apps/web` — React, TypeScript, Tailwind. Голосование, админ-панель и ТВ.
- `apps/api` — Express, правила конкурса, авторизация и QR.
- `apps/api/prisma` — схема MySQL и миграции.
- `packages/contracts` — общие типы API.
- `infra` — запуск и развёртывание.
- `tests/e2e` — сквозные сценарии.
- `docs` — [ТЗ](docs/specification.md) и [правила дизайна](docs/design/rules.md).
