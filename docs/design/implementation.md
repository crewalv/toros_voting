# Клубная афиша

- Голосование. [Утверждённый мобильный референс](concepts/mobile-comparison.png), первая колонка. Трёхстрочный наклонный заголовок, две плашки, зелёный штрих, исходные эмблемы, светлые поля и полноширинная кнопка.
- Экран арены. [Утверждённое направление](concepts/01-club-poster.png), правая часть. Крупный заголовок, пара команд и отдельная светлая зона QR. Фон создан генератором изображений по выбранному макету и оптимизирован в WebP.
- Вход организатора. Внедрён согласованный предпросмотр с композицией [Cruip Open Sign In](https://open.cruip.com/signin): узкая форма по центру и акцентная кнопка во всю ширину. Использованы собственная разметка, фон арены из проекта и светлый `toros-inverse.svg` из сайта «Торос». Код и материалы Cruip не копировались.
- Рабочая панель. Адаптирован [shadcn/ui dashboard-01, New York v4](https://ui.shadcn.com/view/new-york-v4/dashboard-01). Боковое меню, компактная шапка, четыре сводных показателя, управление выбранным матчем на месте графика и таблица матчей. Поверхности светлые, навигация в клубном синем, основные действия в зелёном. [Исходник блока](https://ui.shadcn.com/r/styles/new-york-v4/dashboard-01.json).
- Блоки shadcn/ui распространяются по [лицензии MIT](https://github.com/shadcn-ui/ui/blob/main/LICENSE.md). Текст лицензии приложен как `apps/web/public/shadcn-LICENSE.txt`.
- Типографика. Manrope и Roboto Condensed из [сайта «Торос»](https://denis824-lab.github.io/toros/). Лицензии SIL Open Font License приложены в `apps/web/public/fonts`.
- Эмблемы. «Торос» взят из файлов сайта клуба. «Ижсталь» взята из [карточки ВХЛ](https://www.vhlru.ru/teams/387/). Права на эмблемы остаются у правообладателей.
- Справочник ВХЛ. Все 30 команд сезона 2026/27 сверены с [каталогом лиги](https://www.vhlru.ru/teams/) 10 ноября 2026. Для 29 команд сохранены изображения из каталога ВХЛ, для «Тороса» используется SVG проекта `toros`. Ссылки на профили и исходные файлы указаны в `apps/api/src/vhl-teams.json`. «ХК Тамбов» отображается как «Тамбов», чтобы использовать существующую запись команды.
