# Развёртывание «Тороса» на PHP

Серверу нужны PHP 8.2+, расширения pdo_mysql, gd, mbstring и fileinfo, MySQL, Composer для установки QR-библиотеки и веб-сервер с HTTPS. Node.js нужен на компьютере сборки React. На хостинге приложение работает через PHP.

1. Соберите React на компьютере с Node.js 22.12+ из корня репозитория: `npm ci --ignore-scripts`, затем `npm run build`.
2. Скопируйте **содержимое** `dist/` в `php-api/public/`, сохранив `index.php` и `.htaccess`. На хостинг перенесите дерево проекта с таким же расположением файлов. Назначьте **только `php-api/public/`** корнем сайта. Если панель не позволяет менять корень, попросите поддержку направить поддомен на эту папку.
3. Настройте HTTPS и перенаправление запросов к `/api/*` и страниц React на `index.php`. Для Apache правила есть в `.htaccess` (нужны mod_rewrite и разрешение использовать файл). Для Nginx настройте `try_files $uri $uri/ /index.php?$query_string` и обработку `index.php` через PHP-FPM.
4. Из корня проекта выполните `composer install --working-dir=php-api --no-dev`. Если на хостинге нет Composer, выполните установку на компьютере с совместимым PHP и перенесите `php-api/vendor/`.
5. Создайте в корне проекта файл `.env` по примеру ниже. Параметры подключения задайте в панели хостинга или в файле вне корня сайта. Спецсимволы в пароле MySQL кодируйте для URL.

```dotenv
NODE_ENV=production
PUBLIC_BASE_URL=https://vote.example.ru
DATABASE_URL="mysql://toros:YOUR_PASSWORD@127.0.0.1:3306/toros_voting"
ADMIN_LOGIN=organizer
ADMIN_PASSWORD="YOUR_NEW_PASSWORD"
```

6. Выберите существующую базу либо создайте пустую. Перед работой с существующей базой сохраните резервную копию. Выполните `php php-api/setup.php` из корня. Скрипт создаст схему только в пустой базе, добавит таблицу ограничения запросов и недостающие команды. Существующие матчи, прогнозы и логотипы останутся в базе. Для указанного логина скрипт запишет PHP-хеш пароля и завершит его прежние сессии. Пароль должен быть от 12 до 72 байт. Старые пароли Node.js для других логинов нужно переустановить этим же скриптом по одному.
7. Откройте `/api/health` и `/admin`. Проверьте QR с телефона через мобильную сеть и проведите пробный матч. Настройте резервные копии и проверьте нагрузку перед запуском на арене.

В панели откройте матч и нажмите **Удалить матч**. После подтверждения матч, его прогнозы и результат удаляются вместе. Старый QR перестаёт открывать этот матч.

Для локальной проверки соберите React, скопируйте сборку как в шаге 2 и выполните `php -S 127.0.0.1:8000 -t php-api/public php-api/router.php`. В локальном `.env` укажите `NODE_ENV=development` и `PUBLIC_BASE_URL=http://localhost:8000`. Панель доступна на `http://localhost:8000/admin`.

Тест `node php-api/smoke.mjs` запускайте только на локальном тестовом сервере с отдельной базой: он создаёт матч, участников и прогноз, публикует результат и удаляет созданный матч.
