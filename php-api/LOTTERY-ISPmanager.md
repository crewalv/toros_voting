# Установка временного розыгрыша

1. Сохраните свежие резервные копии файлов сайта и базы.
2. Добавьте файлы public/assets из архива в действующую public/assets.
3. Папку public/lottery-media загрузите в public целиком.
4. Замените public/index.php, сохраняя действующий путь подключения bootstrap.php, затем public/index.html.
5. Откройте /admin2, войдите с действующим логином, вставьте три столбца из Excel без заголовка и нажмите «Подготовить билеты».
6. Нажмите «Открыть экран розыгрыша». Переход выполняется в этой же вкладке. На /lottery нажмите «Начать розыгрыш». Через 5 секунд появится выигравшее место.

Список, оставшиеся в круге билеты и последнее выпавшее место существуют только в оперативной памяти вкладки браузера. Перезагрузка, закрытие вкладки или переход на другой раздел сайта очищают их. Переход между /admin2 и /lottery через кнопки страницы и кнопки браузера назад/вперёд сохраняет данные до перезагрузки. Отдельная вкладка имеет свой независимый розыгрыш. Автоматическое восстановление списка после перезагрузки отсутствует.

История победителей и даты на сервер не передаются. Внутри круга билеты не повторяются. После исчерпания списка начинается новый круг. При двух и более билетах соседние результаты различаются.

SQL выполнять для этой версии не требуется. Если предыдущая версия уже была установлена, существующая таблица TorosLottery может содержать старые тестовые данные. Для их удаления в phpMyAdmin можно выполнить DELETE FROM TorosLottery. Команда удаляет только данные прежнего розыгрыша. Удалять таблицы голосования для обновления не требуется.

При откате верните index.php и index.html из резервной копии.
