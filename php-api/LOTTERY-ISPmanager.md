# Установка розыгрыша в ISPmanager

Розыгрыш работает через PHP API и MySQL действующего сайта. Экран рассчитан на Chromium 103 и окно vMix 1024×576.

1. Создайте свежие резервные копии файлов сайта и всей базы. Скачайте обе копии.
2. В phpMyAdmin выберите рабочую базу и выполните SQL из файла lottery.sql. Повторное выполнение сохраняет загруженный список и результаты. Добавляется отдельная таблица TorosLottery.
3. В папке /var/www/ad270626-387980/data/www/torosscore.ru/php-api разместите lottery.php рядом с действующим bootstrap.php.
4. Содержимое public/assets добавьте в существующую public/assets. Папку public/lottery-media загрузите в public целиком.
5. Замените public/index.php, сохраняя действующий путь подключения bootstrap.php, если он был изменён на сервере. Затем замените public/index.html.
6. Откройте /api/health, затем /admin2. Войдите с действующим логином администратора. Вставьте сектор, ряд и место из трёх столбцов либо строки вида «сектор 1 ряд 5 место 20». Проверьте предварительный список и сохраните.
7. Откройте /lottery в vMix с Width 1024 и Height 576. Запустите розыгрыш из /admin2. Проверяйте отдельным зрительским браузером без входа администратора. После пятисекундной анимации появится выигравшее место.

Кнопки запуска доступны после входа также на /lottery. Внутри круга выигравшие места исключаются. После перебора списка начинается новый круг. При двух и более билетах первый победитель нового круга отличается от последнего победителя предыдущего круга. При единственном билете повторяется это место. Совпадающие сектор, ряд и место считаются одним билетом. Нули в начале числовых значений нормализуются. Поддерживается до 10 000 уникальных билетов, по одному в строке. Заголовки столбцов перед вставкой удаляются. Замена списка очищает историю розыгрыша после подтверждения.

Результаты и оставшиеся билеты сохраняются в базе. Перезагрузка страницы продолжает текущий розыгрыш. При потере связи показывается сообщение, повторный запуск с тем же идентификатором запроса сохраняет выбранный билет.

Для отката верните index.php и index.html из резервной копии. Таблица TorosLottery может оставаться в базе.
