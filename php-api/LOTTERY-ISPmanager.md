# Установка розыгрыша с сохранением текущих билетов

Архив toros-lottery-database.zip предназначен для PHP-сайта. В нём есть папка php-api. Сначала сохраните свежие резервные копии файлов сайта и действующей базы данных. На production обновление автоматически не устанавливается.

## 1. Таблица

В ISPmanager откройте phpMyAdmin для СУЩЕСТВУЮЩЕЙ базы этого сайта. Выберите её слева, откройте «Импорт» и выберите файл php-api/lottery-current.sql из распакованного архива. Нажмите «Вперёд»/«Импорт».

Создаётся только таблица TorosLotteryCurrent. Таблицы матчей, голосов и администраторов не меняются. Новую базу и новый логин администратора создавать не нужно. Повторный импорт этого SQL сохраняет текущие билеты.

Альтернатива для доступа к терминалу: php php-api/migrate-lottery-current.php из основной папки сайта. Это также безопасно при повторном запуске. Выполняйте только один из двух вариантов.

## 2. Файлы

Основная папка сайта: /var/www/ad270626-387980/data/www/torosscore.ru

1. В существующую папку php-api загрузите lottery-current.php из архивной php-api. Он должен лежать РЯДОМ с действующим bootstrap.php, выше public.
2. Добавьте два файла из архивной php-api/public/assets в существующую серверную php-api/public/assets. Старые файлы оставьте.
3. Загрузите папку php-api/public/lottery-media целиком в серверную php-api/public. В ней должны быть idle.mp4, running.mp4 и poster.jpg. Если папка уже существует, замените эти три файла.
4. Замените php-api/public/index.php файлом из архива. Он подключает ../bootstrap.php и ../lottery-current.php.
5. Последним замените php-api/public/index.html.

Не создавайте public/public или php-api/php-api. Не удаляйте и не заменяйте .env, bootstrap.php, vendor, images, эмблемы команд, .htaccess или файлы остальных разделов. Файл lottery-current.sql не нужно размещать в публичной папке. Собирать проект на сервере не требуется.

## 3. Проверка

1. Откройте https://torosscore.ru/lottery-media/poster.jpg — должна появиться картинка колеса.
2. Откройте https://torosscore.ru/lottery-media/running.mp4 — должно проигрываться видео. Если вместо него появляется сайт, файлы загружены не в ту папку. Исправьте расположение, прежде чем проводить розыгрыш.
3. Откройте https://torosscore.ru/admin2, нажмите Ctrl+F5 и войдите с ДЕЙСТВУЮЩИМ логином администратора сайта.
4. Вставьте билеты, по одному в строке, и нажмите «Сохранить билеты». Можно использовать номера с ведущими нулями, имена, произвольный текст или строки из нескольких столбцов Excel. Столбцы одной строки Excel образуют один билет. Три числовых столбца распознаются как сектор, ряд, место. Совпадающие билеты участвуют один раз. Пустые строки пропускаются. Лимит: 10 000 уникальных билетов, до 500 символов на билет и 2 МБ исходного текста.
5. Обновите страницу: список должен остаться.
6. Нажмите «Открыть экран розыгрыша» и большую кнопку «Начать розыгрыш». Через 5 секунд появится результат. Повторять можно без ограничения числа розыгрышей. Внутри круга билеты не повторяются, затем начинается новый круг. Если билетов несколько, два соседних результата различаются.
7. Зрители на /lottery видят анимацию и результат. Запуск доступен только вошедшему администратору. Новая вкладка видит тот же текущий розыгрыш.
8. Для замены списка откройте /admin2, замените текст, нажмите «Сохранить билеты» и подтвердите замену. Старый список, оставшиеся билеты круга и предыдущий результат заменяются одновременно. Отдельной истории дней и победителей приложение не ведёт. Пока идёт пятисекундный розыгрыш, замена списка запрещена.
9. Проверьте также /admin и /display.

## Откат

Верните index.php и index.html из резервной копии. Старые assets сохраняются, поэтому предыдущая сборка продолжит работать. Новую таблицу удалять для отката не нужно.
